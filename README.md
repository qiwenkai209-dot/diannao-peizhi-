# 🏛️ 展馆智能集群综合管控系统 · 国文创主控与受控终端双独立软件

专为展馆展厅、多媒体互动展项、工控集中机房量身定制的**主控端**与**受控端（控制终端）**两款独立运行软件。具备极致轻量化守护、局域网全网段雷达秒级搜索、开机自启预设应用与延时启动管理、后台静默隐藏、全局热键瞬间呼出界面、集中监控与批量管控全套能力，原生集成**国文创商用加密机通信协议**、**远程动态签发授权**体系，以及专为快思聪、AMX 等硬件中控打造的 **UDP 智能中控接口**。

## 🤖 软件一：展馆控制终端 (Controlled Terminal · `gwc_agent_app.py` / `展馆控制终端.exe`)

部署在各展厅、展项的多媒体工控机、触控一体机或渲染服务器上：

1. **🚀 预设应用置顶常驻管理（开机自启 + 延时启动）**：
   - 界面最上方卡片**常驻展开（不折叠）**，一目了然显示全部预设应用列表（应用名、开机自启开关、延时启动秒数、程序路径与运行参数）。
   - 支持可视化一键【➕ 添加预设应用】、【✏️ 编辑】、【🚀 立即测试启动】与【🗑️ 移除】。
   - **智能开机延时调度**：终端开机自启后，自动在后台按配置好的延时秒数倒计时启动各展项软件，杜绝多软件开机瞬时争抢显卡与 CPU 导致崩溃卡顿。
   - 深度兼容快捷方式（`.lnk`）、环境变量（`%APPDATA%` / `%PROGRAMFILES%`）与相对工作目录（自动推导 `cwd`），无论任何多媒体软件均能稳定拉起。
2. **🎨 极简大气收纳设计（其他功能统合折叠）**：
   - 全局热键与静默守护、集群通信服务与端口标注（`TCP: 9888`、`UDP: 9887`、`VNC: 5900`）、专属商业授权等高级运维功能统一收纳在折叠卡片中，首屏操作极度精简高效。
3. **⚡ 极致轻量化与超低资源消耗**：
   - 显卡占用探测增加异常冷却保护（杜绝无独立显卡工控机频繁衍生子进程浪费 CPU）。
   - 本地配置与进程快照采用基于文件修改时间的内存缓存，空闲时 CPU 占用稳定在 **0.0%**，内存仅占用几十兆。
4. **🔒 商业授权强制弹窗保护**：
   - 采用全新 2026 终端商业授权体系，支持自定义**小时、月度、永久**时长。
   - 未授权或授权到期时，以全屏前置模态弹窗锁定，不展示操作菜单，杜绝未经授权使用。
   - 支持主控端远程一键无感换码续期与热覆盖。
5. **🛡️ 展馆工控一键优化与防休眠**：
   - 一键关闭屏幕休眠、关闭硬盘睡眠、屏蔽 Windows 自动更新打扰、一键物理内存深度压缩释放（`EmptyWorkingSet`）。
6. **🌙 全局热键与隐蔽守护**：
   - 支持开机静默隐藏运行 (`--hide`)，按全局热键（默认 `Ctrl+Q`，可自定义）瞬间呼出或隐藏配置界面。

## 🖥️ 软件二：智能集群主控端 (Master Controller Hub · `gwc_master_app.py` / `展馆智能集群主控端.exe`)

部署在展馆中控室总控机、展厅管理员电脑或大屏调度主机上：

1. **🔍 局域网在线受控端雷达秒级扫描**：
   - UDP 9887 全网段广播主动探测，秒级发现所有在线受控机（名称、IP、CPU/GPU占用、内存、授权状态）。
   - 支持一键纳管、自动同步受控端自定义主机名。
2. **📊 全馆设备状态集中监控大厅**：
   - 统一展示从机 CPU、GPU、内存、前台活跃程序、网络延迟等关键健康指标，放不下时平滑滚动播放。
   - 全馆全局快捷调度：全馆一键关机、一键重启、一键静音、统一音量设置。
3. **🎯 选定工控机精准调度**：
   - 远程电源：指定关机、重启；
   - 精准音量：实时调节受控机系统音量（0~100%）并实时生效；
   - 进程强杀：实时查看当前运行程序，一键强制结束异常进程；
   - 预设程序调用：主控下拉框直接选择从机上报的预设程序，远程秒级启动。
4. **📁 受控端自定义目录文件管理器**：
   - 支持指定受控机任意自定义工作路径，提供远程文件列表浏览、本地文件上传、从机文件下载、文件安全删除全套操作。
5. **💾 远程系统配置备份与一键下发恢复**：
   - 主控端自动发现设备，可一键向选定受控端发起全系统策略备份回传；
   - 支持将备份档案一键远程下发到受控机自动无感恢复。
6. **🛡️ 商业授权远程签发中枢**：
   - 支持选中设备后，选择“1小时 / 24小时 / 1个月 / 1年 / 永久有效”，点击【远程签发并激活】，主控加密运算激活码并直接下发，受控端实时解密并自动更新授权状态。

## 📡 展馆第三方集中智能中控多协议总线 (UDP / TCP / HTTP / 串口) 与视频推流规范

为无缝接入中控室主流硬件（**快思聪 Crestron、AMX、华为/快捷/台达中控主机、第三方智能中控平板、网页Web大屏系统、物理串口按键网关**），主控端特别开启了四合一全协议中控调度总线。

### 1. 通信总线协议与端口分布
- **UDP 控制接口**：端口 `9889`（无连接极速响应，支持单包指令与自动 ACK）
- **TCP 控制接口**：端口 `9890`（面向快思聪/AMX 等长短连接 Socket，以 `\n` 分隔）
- **HTTP RESTful API**：端口 `9891`（面向 Web 大屏、平板浏览器、小程序、curl，支持跨域 CORS）
- **物理串口 (RS232/RS485)**：支持选择本机 COM 端口（如 COM1/COM2/COM3），波特率 9600/115200
- **字符编码**：UTF-8 / ASCII
- **格式支持**：兼容**纯文本指令（冒号分隔）**与**标准 JSON 报文**双模通信。

---

### 2. 视频推流与实时桌面监看地址规范

各工控机在局域网内拥有独立的 IP 地址，中控平板、大屏流媒体播放器或 Web 页面可通过以下地址直接拉流：

| 流媒体协议 | 拉流 URL 格式规范 | 典型应用场景 |
| :--- | :--- | :--- |
| **原生 VNC 控制流** | `vnc://<工控机IP>:5900` | 主控端内嵌远程桌面、TightVNC 客户端直连控制 |
| **WebRTC 低延时监看** | `webrtc://<工控机IP>:5900/live` | 中控室超低延迟无感画面回传 |
| **HTTP MJPEG 画面流** | `http://<工控机IP>:5901/stream.mjpg` | 浏览器、前端大屏网页 `<img>` 标签直接免插件播放 |
| **RTSP 展厅监控流** | `rtsp://<工控机IP>:8554/live` | 集中监控 NVR、OBS、VLC 播放器拉流 |

---

### 3. HTTP RESTful API 接口速查 (端口 9891)

| 请求方法与路径 | 参数说明 | 功能说明与返回示例 |
| :--- | :--- | :--- |
| `GET /api/devices` | 无 | 获取所有在线工控机清单、CPU/GPU/内存、**视频推流地址** |
| `GET /api/status` | 无 | 获取中控服务器健康状态与在线工控机总数 |
| `GET /api/control?action=...` | `action`, `ip`, `volume`, `app_name` | URL 超链接一键控制（方便直接做在前端网页按键上） |
| `POST /api/control` | JSON Body: `{"action":"..."}` | 下发 JSON 控制指令（支持跨域 CORS） |

**URL 一键控制快捷示例**：
- 全馆一键关机：`http://<Master_IP>:9891/api/control?action=all_shutdown`
- 全馆一键重启：`http://<Master_IP>:9891/api/control?action=all_reboot`
- 设定全馆音量：`http://<Master_IP>:9891/api/control?action=all_volume&volume=80`
- 设定单机音量：`http://<Master_IP>:9891/api/control?action=dev_volume&ip=192.168.1.50&volume=65`
- 单机启动应用：`http://<Master_IP>:9891/api/control?action=dev_launch&ip=192.168.1.50&app_name=数字沙盘`

### 4. UDP / TCP / 串口 指令集规范列表

| 指令功能 | 纯文本格式命令 (Text) | 标准 JSON 格式命令 | 说明与示例 |
| :--- | :--- | :--- | :--- |
| **全馆一键关机** | `ALL_SHUTDOWN` | `{"action":"all_shutdown"}` | 调度全馆所有已连接工控机安全关机 |
| **全馆一键重启** | `ALL_REBOOT` | `{"action":"all_reboot"}` | 调度全馆所有已连接工控机安全重启 |
| **全馆一键静音** | `ALL_MUTE` | `{"action":"all_mute"}` | 全馆所有工控机一键静音 |
| **全馆解除静音** | `ALL_UNMUTE` | `{"action":"all_unmute"}` | 全馆所有工控机恢复声音播放 |
| **全馆统一音量** | `ALL_VOLUME:<0-100>` | `{"action":"all_volume","volume":75}` | 统一全馆音量。例如：`ALL_VOLUME:80` |
| **全馆启动预设程序** | `ALL_LAUNCH:<程序名>` | `{"action":"all_launch","app_name":"数字沙盘"}` | 全馆匹配该应用名的工控机统一启动 |
| **单机精准关机** | `DEV_SHUTDOWN:<IP>` | `{"action":"dev_shutdown","ip":"192.168.1.50"}` | 仅让 IP 为 `192.168.1.50` 的设备关机 |
| **单机精准重启** | `DEV_REBOOT:<IP>` | `{"action":"dev_reboot","ip":"192.168.1.50"}` | 仅让 IP 为 `192.168.1.50` 的设备重启 |
| **单机精准音量** | `DEV_VOLUME:<IP>:<0-100>` | `{"action":"dev_volume","ip":"192.168.1.50","volume":60}` | 调节单台音量。例如：`DEV_VOLUME:192.168.1.50:60` |
| **单机启动指定程序** | `DEV_LAUNCH:<IP>:<程序名>` | `{"action":"dev_launch","ip":"192.168.1.50","app_name":"3D环幕"}` | 调度单台工控机启动指定的预设程序 |
| **单机结束进程** | `DEV_KILL:<IP>:<PID或进程名>` | `{"action":"dev_kill","ip":"192.168.1.50","target":"Player.exe"}` | 调度指定设备强杀进程 |
| **心跳与状态查询** | `PING` | `{"action":"ping"}` | 查询主控状态，主控回传在线设备总数 |

### 5. 第三方中控对接调用示例

#### ① HTTP API 调用示例 (cURL / 浏览器)
```bash
# 获取所有工控机状态与推流地址
curl -X GET "http://192.168.1.100:9891/api/devices"

# 发送控制指令: 全馆统一音量为 85%
curl -X GET "http://192.168.1.100:9891/api/control?action=all_volume&volume=85"
```

#### ② TCP Socket 调用示例 (Python / 快思聪)
```python
import socket

# 连接主控端 TCP 9890 端口
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect(("192.168.1.100", 9890))
s.sendall(b"ALL_VOLUME:80\n")
ack = s.recv(1024)
print("收到主控 TCP 应答:", ack.decode("utf-8"))
s.close()
```

#### ③ 物理串口对接示例 (RS232 / RS485 / 串口网关)
- 打开串口（如 `COM1`），设置波特率 `9600`，数据位 8，停止位 1，无校验。
- 发送文本命令：`ALL_SHUTDOWN\r\n`
- 主控端即时向串口写回 ACK：`ACK:已向全馆 8 台工控机下发关机指令\r\n`

#### ④ 快思聪 (Crestron SIMPL+) 伪代码对接示例
```c
Function SendToGWC(STRING strCmd)
{
    SIGNED_INTEGER nSocket;
    nSocket = SocketUDP_Create();
    // 向主控电脑 192.168.1.100 端口 9889 发送
    SocketUDP_Send(nSocket, "192.168.1.100", 9889, strCmd, Len(strCmd));
}

PUSH Btn_All_Shutdown
{
    SendToGWC("ALL_SHUTDOWN");
}
```
