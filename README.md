# 🏛️ 展馆系统配置与网络设置及电脑优化工具 · 国文创商业双模版

专为展馆展厅中控机、多媒体互动工控机及多机集群定制的系统配置、深度优化与集中控制系统。具备**工控单机优化**与**主控集群综合管理**双模一体化能力，原生集成**国文创商用加密机通信协议**与**远程免密授权**体系。

---

## 🌟 核心架构与功能一览

### 1. 🔄 双功能模式架构 (单机优化 + 主控综合管理)
- **模式一：🏠 工控单机与电脑优化模式**
  - **网络适配器与 IPv4 配置**：多网卡扫描，静态 IP / 掩码 / 网关 / DNS 免插拔配置与 DHCP 一键切换。
  - **展馆工控机系统策略**：UAC、Defender、自动更新、系统防火墙、网卡节能、快速启动、触摸屏边缘手势、屏幕常亮/休眠、RDP 免密远程登录一键管控（支持 `ALLON` 全开与 `ALLOFF` 恢复）。
  - **深度优化与清理**：调用底层 `EmptyWorkingSet` 遍历回收系统全部进程工作集内存；清理系统临时垃圾；一键深度重置 Winsock 与 TCP/IP 协议栈；DNS 缓存刷新与网络体检。
  - **自启动项与右键管理**：枚举注册表及启动文件夹自启项并安全隔离禁用；Win11 经典完整右键一键切换；注入取得管理员所有权、此处打开 CMD 等右键菜单；已装软件扫描。
  - **💾 配置完成系统一键备份与恢复**：
    - 一键将当前系统网络配置、展馆策略注册表、启动项状态、预装软件清单导出打包为 `.gwcbackup` 备份包。
    - 支持本地选择备份包一键全自动还原恢复（自动写回网卡参数、重置策略、恢复自启、校验预装软件环境）。
    - 支持将本地生成的备份包一键上传给主控归档存储。
  - **📡 从机受控服务**：在后台建立与中控的国文创强加密长连接，实时采集上报 CPU、内存、磁盘、实时网速、前台活动窗口与活跃进程；随时响应中控下达的远程关机、重启、音量调节、应用启动、进程强杀与恢复还原指令。

- **模式二：🖥️ 展馆主控集群综合管理模式**
  - **全馆设备监控大厅**：
    - 集中监听局域网所有工控机（端口 9888），动态展现计算机名、IP、系统、CPU使用率、内存使用率、磁盘占用、当前前台活动窗口与授权状态。
    - 快速全局批量操作：全馆一键关机、全馆一键重启、全馆一键静音、全馆批量调用应用。
  - **选定工控机即时控制**：
    - ⚡ **电源控制**：远程关机、远程重启。
    - 🔊 **精准音量控制**：0-100% 音量精准数值设定、一键静音与解除静音。
    - 🚀 **远程应用调用**：指定远程可执行程序或脚本路径，一键远程调用启动。
    - 🛑 **应用与进程强杀**：实时枚举选定从机正在运行的软件与进程（PID、名称、内存占用），一键强制结束进程（Kill Process）。
  - **🖥️ 嵌入式开源 VNC 远程控制**：
    - 从机内置轻量级标准 VNC RFB 3.8 服务（开放 5900 端口，兼容 UltraVNC、TightVNC、RealVNC、TigerVNC 直连）。
    - 主控端提供原生内嵌远程桌面控制视窗：实时流畅传输桌面画面，支持鼠标移动、点击、滚轮、键盘按键映射与画质自适应切换。
  - **📁 远程双向文件传输管理器**：
    - 主控端提供双栏式文件浏览器（左侧主控本地磁盘，右侧从机远程磁盘与驱动器）。
    - 支持主控本地文件向从机上传、从机文件向主控下载、远程新建文件夹与远程安全删除。
  - **💾 主控备份中心与远程下发**：
    - 集中归档所有工控机上传的系统备份文件。
    - 支持主控主动命令从机生成最新备份并上传入库。
    - 支持主控将选中的备份包一键下发到指定工控机，从机静默自动执行全系统配置还原！
  - **🛡️ 国文创商业授权中枢**：
    - 从机支持将 8 位设备申请码随心跳自动上报主控。
    - 主控管理员在监控大厅可直接选定工控机与授权时长（永久有效、1年、180天等），点击【一键远程授权激活】，主控即刻自动签发 12 位激活码并下发，从机秒级自动核销激活，彻底告别逐台机器人工敲码！
    - 内置独立的《国文创加密机》计算器终端，支持手工输入申请码运算签发激活码。

## 🛡️ 国文创商业加密机通信与安全机制

本项目深度集成**国文创通用加壳加密引擎 (Universal Shield Engine)** 与 **商业授权核心 (Universal License Core)**：

1. **主从通信全包强加密**：
   - 通信协议（GWCC 协议）采用 HMAC-SHA256 计数器模式派生与明文等长的伪随机密钥流进行异或流加密。
   - 每个报文帧携带 8 字节时间戳、4 字节动态随机 Nonce 与 16 字节 HMAC 签名，严格防范重放、中间人窃听与数据篡改。
2. **防二次激活安全体系**：
   - 8 位随机设备申请码（`XXXX-XXXX`）：基于硬件特征（磁盘卷标、MAC、CPU）结合动态 Nonce 混淆生成。
   - 12 位一次性商业授权激活码（`XXXX-XXXX-XXXX`）：包含硬件特征校验和、代际控制、有效期与 HMAC 数字签名。
   - 单次核销防克隆：激活成功后 Nonce 立即自增翻转销毁，旧激活码立即失效。
3. **从机支持主机远程授权**：
   - 未授权工控机自动通过加密通道向中控大厅请求授权。
   - 主控端内置签发算法，一键免密远程下发激活，内存即刻生效。

## ☁️ GitHub Actions 云端全自动执行与发布

本项目已配置完善的 **GitHub Actions CI/CD 流水线**（`.github/workflows/build.yml`）：

- **工作流地址**：[All workflows](https://github.com/qiwenkai209-dot/diannao-peizhi-/actions)
- **触发机制**：代码推送至 `main` / `master` 分支或在 GitHub Actions 页面点击 **Run workflow** 手动触发。
- **云端构建流程**：
  1. Windows 最新虚拟机拉取源码并配置 Python 3.11。
  2. 自动安装 `pyinstaller`、`pillow`、`psutil`。
  3. 执行 `python protect_build.py` 进行多模块 AST 编译、HMAC 密钥流加壳与单文件 EXE 独立封装。
  4. 自动上传受保护构建成果物至 **Artifacts**（保存 30 天）。
  5. 自动发布至 **GitHub Releases**，提供下载。

## 🛠️ 构建与运行指南

### 1. 源码直接运行 (开发调试)
运行环境：Python 3.8+ (Windows)
```bash
# 安装必要依赖
pip install pyinstaller pillow psutil

# 启动双模综合管理工具
python net_config_tool.py

# 指定模式快速启动
python net_config_tool.py --master   # 直接启动主控综合管理大厅
python net_config_tool.py --agent    # 直接启动工控从机受控模式
```

### 2. 执行国文创加壳加密与打包构建
运行项目自带的一键加壳脚本：
```bash
python protect_build.py
```
> 脚本会自动完成全部功能模块的根级加密加壳、注入商业授权守卫，并在 `dist/` 目录生成带有管理员权限和齿轮图标的单文件可执行文件《展馆系统配置与网络设置及电脑优化工具.exe》。
