# 🏛️ 展馆系统配置与网络设置及电脑优化工具

专为展馆展厅中控机、多媒体互动工控机及日常 Windows 电脑定制的系统配置与综合深度优化工具。

---

## 🌟 核心功能一览

### 1. 🌐 展馆与网络设置
- **以太网 / IPv4 配置**：支持扫描网络适配器，自定义 IP、子网掩码、网关、首选/备用 DNS，免插拔网线即时生效。
- **DHCP / 静态 IP 自由切换**：支持一键切换 DHCP 自动获取或快速填入展馆标准化 IP 模板（`192.168.10.11`）。
- **展馆工控机系统策略**：
  - 用户账户控制 (UAC) 关闭与恢复
  - Windows Defender 策略优化
  - Windows 自动更新彻底关闭
  - 系统防火墙全配置关闭/恢复
  - 网卡节能策略关闭（防止网卡休眠掉线）
  - 快速启动关闭（防止异常断电丢配置）
  - 触摸屏边缘滑动手势禁用
  - 屏幕常亮与永不休眠配置
  - RDP 远程桌面免密登录（专供内网远程维护）
- **批量操作**：`ALLON` 展馆一键配置（批量应用所有策略与网络），`ALLOFF` 恢复系统默认设置。

### 2. ⚡ 电脑深度优化
- **物理内存监控与深度释放**：
  - 实时读取系统物理内存总计/已用/可用容量及占用百分比。
  - 遍历系统各进程工作集调用底层 `EmptyWorkingSet` API，快速回收闲置内存。
  - 安全扫描并清理系统临时文件与垃圾缓存（`%TEMP%` 与 `Windows\Temp`）。
- **一键深度网络修复与诊断**：
  - 重置 Winsock 目录 (`netsh winsock reset`)
  - 重置 TCP/IP 协议栈 (`netsh int ip reset`)
  - 刷新并重新注册 DNS 解析缓存
  - 清理系统 ARP 映射缓存
  - 网络连通性一键体检与诊断（回环 127.0.0.1、网关连通性、公共 DNS Ping、域名解析测试）
  - 软重启网络适配器
- **系统响应与注册表性能优化**：
  - 加速卡死程序与关机服务超时（缩短至 2 秒，告别关机转圈）
  - 禁用 Windows 错误报告 (WerSvc) 后台收集与弹窗
  - 禁用任务栏搜索框 Bing 联网联想（本地搜索秒出结果）
  - 禁用后台 GameDVR 常驻
  - 一键激活解锁 Windows 系统级【卓越性能 (Ultimate Performance)】电源计划

### 3. 🚀 开机启动项管理 (启动禁用)
- 智能扫描当前用户注册表 (HKCU)、系统注册表 (HKLM) 的 Run 自启键及两大启动文件夹。
- 支持选定启动项一键【禁用】（安全转存至 `Run-Disabled` 隔离）或【恢复启用】。
- 支持彻底删除无用自启项、快速打开启动文件夹、打开任务管理器启动页。

### 4. 🗃️ 软件与注册表管理
- 智能扫描 64 位、32 位及用户级已安装软件清单。
- 支持按软件名称、发布者实时搜索过滤。
- 一键调用官方卸载向导或复制注册表卸载命令行。

### 5. 🖱️ 鼠标右键菜单管理
- **快捷实用增强**：
  - Win11 现代折叠右键与 Win10 经典完整右键一键平滑切换（平滑重启资源管理器）
  - 一键添加/移除【👑 取得管理员所有权】右键菜单
  - 一键添加/移除【⚡ 在此处打开 CMD (管理员)】与【📂 在此处打开 PowerShell (管理员)】
  - 一键切换显示/隐藏已知文件扩展名及隐藏文件
- **第三方应用右键扫描与彻底删除**：
  - 深度遍历文件、文件夹、桌面空白处、磁盘等位置的 Shell 与 Shell 扩展（shellex）右键项。
  - 智能区分“第三方应用生成”与“Windows 系统内置”。
  - 支持彻底删除第三方流氓软件或卸载残留的右键菜单，清除无用右键项目，保护系统右键清爽整洁。

## 🛠️ 构建与运行

### 1. 源码运行
运行环境：Python 3.8+ (Windows)
```bash
python net_config_tool.py
```
> 本工具需要管理员权限运行，若以普通权限启动，工具会自动请求 UAC 提权。

### 2. 打包为单文件 EXE
通过 PyInstaller 构建：
```bash
pyinstaller -F -w -i gear.ico --add-data "gear.ico;." -n "展馆系统配置与网络设置及电脑优化工具" --clean net_config_tool.py
```
